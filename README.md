# 분수트레이너

초등학교 4~6학년의 개인 학습과 교실 전자칠판 수업을 위한 분수 학습 서비스입니다. Vanilla HTML/CSS/JavaScript로 구현되어 설치·빌드 없이 사용합니다. 전자칠판 수업은 바로 시작하며, 개인 학습인 전국학급랭킹전은 학교·학년·반과 주간 닉네임으로 입장합니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. 일정한 주소에서 학습 기록을 관리하려면 프로젝트 폴더에서 로컬 서버를 실행하세요.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://localhost:8000`으로 접속합니다. 기존 `작업툴`의 로컬 서버 실행 배치 파일도 사용할 수 있습니다. 정적 호스팅에는 `index.html`, `css/`, `js/`, 학교 검색용 `elementaryschooldata.json`을 함께 올립니다. 학교 검색과 온라인 랭킹은 로컬 서버 또는 정적 호스팅 주소에서 사용하세요.

## 사용 방법

1. **선생님과 함께 수업 / 전국학급랭킹전**을 선택합니다. 홈 상단에는 학급 랭킹·학습 기록·단축키 안내를 제공합니다.
2. 랭킹전은 학교·학년·반 선택 → 닉네임 주사위 → 확정 → 등록된 닉네임으로 입장 순서입니다.
3. 학년 → 단원 → 문제 유형 → 기초·기본·도전 → 5·10·20문제를 선택합니다. 랭킹전은 카드 버튼으로 유형을 고르며 대분수·받아내림 포함 체크박스와 학습 도구 설정이 없습니다.
4. 랭킹전에서는 답을 입력하고 확인합니다. 전자칠판 수업은 학생들이 공책에 푸는 동안 문제만 크게 제시합니다.

5단원·29유형을 제공하며 4학년의 **자연수 − 대분수**도 선택할 수 있습니다. 4·5학년 덧셈과 뺄셈 단원에서는 덧셈만 또는 뺄셈만 골고루 섞어 출제할 수도 있습니다.

### 전자칠판 수업

- 힌트 → 정답 → 풀이를 필요한 때에 공개합니다. 풀이는 이전/다음 단계로 넘깁니다.
- 다음 문제는 정답을 숨긴 상태로 시작하며, 이전 문제로 돌아가면 공개 상태를 기억합니다.
- **새 문제**는 현재 문제를 같은 유형으로 교체합니다. 마지막 문제의 수업 마무리 화면에서 **새 문제 세트**를 시작합니다.
- 수업 마무리 화면의 **이번 회차 문제와 정답 보기**를 펼치면 해당 세트의 문제와 정답을 함께 확인합니다.
- **유형 변경**으로 설정을 바꿀 수 있고, 시작하기 전 **진행 중인 문제로 돌아가기**로 돌아갈 수도 있습니다.
- FHD 1920×1080을 중심으로 설계했으며 전체화면을 지원합니다.

| 키 | 동작 |
|---|---|
| → / ← | 다음 / 이전 문제 |
| Space | 정답 공개 |
| H | 힌트 |
| S | 풀이 공개; 정답 공개 전이라면 먼저 정답 공개 |
| F | 전체화면 진입 / 종료 |
| T | 타이머 시작 / 일시정지 |
| R | 타이머 초기화 (일시정지 상태) |
| Esc | 브라우저 전체화면 또는 도움말 종료 |

입력 칸 및 도움말 안에서는 수업 단축키가 동작하지 않습니다.

### 전자칠판 타이머

- 전자칠판 설정의 **학습 도구**에서 타이머를 선택합니다. 기본은 사용 안 함이며 10·20·30·60초 또는 1~3600초를 직접 설정합니다. 시간 종료 후에도 계속 풀 수 있고 자동으로 다음 문제로 넘어가지 않습니다. 전국학급랭킹전에서는 타이머를 사용하지 않습니다.
- 전자칠판에서는 시간 종료 시 정답 공개를 선택할 수 있습니다. 이미 정답을 공개했다면 현재 풀이·그림을 유지합니다. 문제 이동·설정·도움말·창 숨김 때 타이머를 멈추며 이전 문제로 돌아오면 남은 시간을 유지합니다. 시작 버튼으로 다시 진행합니다.

### 전국학급랭킹전

- 학교를 검색하고 4~6학년·1~30반을 선택합니다. 닉네임은 **공부하는 + 고양이**처럼 `~하는`과 동물·식물을 조합하며 발급 과정마다 최대 10번 주사위를 굴리고 나온 후보 중에서 고릅니다. 확정 버튼은 서버에 닉네임을 등록하고, 입력칸의 등록된 닉네임으로 입장합니다. 같은 반·같은 주 안에서 닉네임은 중복되지 않습니다.
- 닉네임은 월요일 오전 8시(한국 시간)에 시작하는 해당 주간의 아이디입니다. 같은 학교·학년·반과 닉네임으로 다른 기기에서도 입장할 수 있습니다. 잊었다면 새 닉네임을 발급받으며 이전 닉네임 점수는 합쳐지지 않습니다. 새 주간에는 다시 등록합니다.
- 학생이 난이도를 선택합니다. 정답 기본 점수는 유형별 **100~300점**, 덧셈·뺄셈별 섞기 **350점**, 골고루 연습하기 **500점**에 난이도 배수(기초 **1배**, 기본 **2배**, 도전 **3배**)를 적용합니다. 도움 없는 첫 시도 정답은 **+50점**, 2연속부터 보너스가 **100점씩 증가해 최대 +500점**입니다. 시간 보너스는 없습니다. 정답 판정과 첫 풀이 정답률은 기존 기준을 유지합니다.
- 5문제 이상을 끝까지 학습한 새 세트의 점수를 학급과 개인에 각각 같은 값으로 반영합니다. 중간 종료·건너뛴 문제·오답 재학습 세트는 반영하지 않습니다. 같은 세트를 재시도해도 서버 영수증으로 중복 합산을 막습니다. 반영 실패 시 학습 기록에서 같은 주 안에 재시도할 수 있습니다.
- **학급 랭킹 / 개인 랭킹**을 선택하면 이번 주 실시간 점수와 지난주 결과를 함께 봅니다. 각 상위 50개 목록과 조회 가능한 우리 반·본인 기록을 표시합니다. 매주 월요일 오전 8시부터 새 주간의 점수를 0에서 쌓고, 이전 주 컬렉션의 누적 결과를 보존해 다음 주 동안 함께 보여 줍니다. 별도 초기화 서버 작업 없이 주간별 저장 공간을 전환하는 방식입니다.
- **나의 성장** 화면과 경험치·레벨·배지 지급은 제거했습니다. 이전 성장 저장 데이터와 학습 기록은 보존합니다. **이전 방식의 랭킹 기록**에서는 기존 온라인 성장 점수·명시된 데모·예전 점수를 별도로 조회하며 새 주간 점수와 합산하지 않습니다.
- 온라인 입장·랭킹 조회 때만 Firebase SDK와 서버에 연결합니다. 인터넷과 해당 컬렉션의 읽기·쓰기 권한이 필요합니다. 실제 운영 쓰기·보안 규칙 검증 범위는 [검증 결과](docs/TEST-RESULTS.md)를 확인하세요. 연결 실패 시 샘플 데이터를 실제 랭킹처럼 표시하지 않습니다.

### 개인 학습과 기록

정답을 맞히면 획득 점수와 보너스가 반짝이는 효과로 나타나며, 회차 결과에는 총 획득 점수와 격려 메시지가 표시됩니다. 유형·난이도 카드에서 현재 선택의 기본 점수를 미리 확인할 수 있습니다. 동작 줄이기 설정에서는 애니메이션 없이 점수를 표시합니다. 기존 기록과 랭킹 누적 점수는 재계산하거나 초기화하지 않습니다.

- 분수 답은 분자·분모, 대분수 답은 자연수·분자·분모를 입력합니다. 자연수 답은 자연수 칸만 입력해도 됩니다.
- Tab으로 이동하고 Enter로 확인합니다. 통분은 두 분수, 비교는 기호, 동치분수 빈칸과 공통분모는 자연수를 입력합니다.
- 4학년 계산은 같은 값의 분수를 정답으로 인정합니다. 기약분수를 요구하는 문제는 약분 여부도 확인합니다.
- 오답 뒤에는 힌트와 재도전을 제공합니다. 정답 또는 풀이를 먼저 확인한 문제는 재학습 대상이 됩니다.
- 정답률은 **전체 문제 중 첫 제출에 정답인 문제의 비율**입니다. 재도전 성공 개수는 따로 표시합니다. 힌트·그림을 참고한 첫 제출도 포함됩니다.
- 학습을 끝내거나 **여기까지 결과 보기**를 누르면 날짜·설정·정답·시도·시간·오답이 저장됩니다. 건너뛴 문제도 다시 풀 수 있습니다.
- `localStorage`에 최근 100회까지 저장합니다. 저장이 제한된 브라우저에서는 현재 창의 메모리에 보관하고 화면에 알립니다. 기록은 브라우저/접속 주소별로 분리되며 기기 간 동기화는 없습니다.

## 검증

계산·출제 테스트는 Node.js 20 이상에서 추가 패키지 없이 실행합니다.

```powershell
node --test tests/math.test.cjs tests/generator.test.cjs tests/storage-extension.test.cjs tests/extensions.test.cjs tests/session-extras.test.cjs tests/competition.test.cjs tests/competition-ui.test.cjs
```

실제 브라우저 검증은 Windows에 설치된 Chrome, Python, `websocket-client`를 사용합니다. 테스트 도구만 해당 환경을 필요로 하며 서비스 자체에는 Python·Node가 필요하지 않습니다.

```powershell
python tests/browser_test.py --scenarios
python tests/extension_scenarios.py
python tests/ranking_scenarios.py
python tests/competition_scenarios.py
```

테스트는 전용 Chrome 프로필과 로컬 서버를 열고 종료합니다. 보고서와 화면 캡처는 `tests/artifacts/`에 생성됩니다. 일반 브라우저의 학습 기록은 건드리지 않습니다.

계산은 `js/fraction.js`, 출제는 `js/problem-generator.js`, 저장은 `js/storage.js`, 분수 표시·시각 모델은 `js/ui.js`, 학습 흐름과 화면은 `js/app.js`가 담당합니다. `gamification.js`의 점수 계산과 `timer.js`의 교사 타이머는 `session-extras.js`로 연결됩니다. `ranking.js`는 학교 검색·기존 랭킹·Firebase 연결을 제공하고 `ranking-ui.js`가 기존 조회 화면을 담당합니다. `competition.js`와 `competition-ui.js`는 주간 닉네임·학급/개인 집계·실시간 랭킹 화면을 담당합니다. `css/classroom.css`는 전자칠판 전용, `extensions.css`는 교사 타이머와 학습 점수, `ranking.css`와 `competition.css`는 랭킹 스타일입니다.

기존 저장 키 `bunsu.learning.v1`, `bunsu.game.v1`, `bunsu.class.v1`, `bunsu.ranking.v1`과 데이터는 유지합니다. 주간 아이디·주사위 후보용 `bunsu.competition.identity.v1`, `bunsu.competition.drafts.v1`을 추가하고 학습 기록에 선택 필드 `competition`을 저장합니다. 기존 학교 데이터와 Git 작업 도구도 보존했습니다. 예전의 오답 3초 대기·자동 다음 문제 전환은 사용하지 않습니다. `codex-state.txt`, `git-diff.txt`, `git-status.txt` 및 테스트 산출물은 `.gitignore`로 커밋 대상에서 제외합니다.
