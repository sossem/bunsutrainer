# 강원교육 서체

제목: 강원교육튼튼 (GangwonEduPower.woff2)
본문: 강원교육모두 Light (GangwonEduModu-Light.woff2)

저작권: 강원특별자치도교육청.
공식 안내: https://www.gwe.go.kr/main/content.do?key=m2307211207715

공식 안내에 따라 웹·모바일을 포함한 매체에서 무료 사용하며, 서체 자체를 유료 양도하거나 판매하지 않습니다.
웹폰트 파일 출처:
- https://github.com/fonts-archive/GangwonEduPower
- https://github.com/fonts-archive/GangwonEduModu

외부 폰트 서버 연결 없이 사용하도록 WOFF2 파일을 함께 제공합니다. 수학 수식과 숫자 입력은 기존 폰트 목록을 유지합니다.
