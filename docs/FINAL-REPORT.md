# 분수 교실 구현 보고서

## 기존 서비스 분석

기존 서비스는 단일 HTML 안에 4학년의 같은 분모 덧셈·뺄셈, 타이머, 정답 공개, Firebase 전국 학급 랭킹이 결합되어 있었다. 교차 곱 기반 동치 판정과 세로 분수 표시에는 재사용 가치가 있었으나, 개인 학습 기록과 오류별 피드백, 다른 학년·단원, 전자칠판 전용 화면은 없었다. 상세 분석은 [IMPLEMENTATION.md](IMPLEMENTATION.md)에 기록했다.

## 새 서비스 구조

학습 방식 → 학년 → 단원 → 문제 유형 → 난이도·문제 수 순서로 시작한다. 개인 학습과 전자칠판 수업은 다른 화면과 흐름을 사용한다. 기본 학습은 외부 프레임워크·SDK·웹폰트·서버 없이 정적 파일로 실행한다. 온라인 랭킹 조회·참여 때만 Firebase SDK와 서버를 사용한다. 이전 작업이 중단된 뒤에도 생성된 파일과 미완성 변경을 보존하고 연결이 누락된 타이머·성취·랭킹을 통합했다.

## 학년별 구현 내용

| 학년 | 단원 및 유형 |
|---|---|
| 4학년 | 같은 분모의 진분수 덧셈·뺄셈, 합이 1보다 큰 덧셈, 1−분수, 대분수 덧셈·뺄셈, 자연수−대분수: 7유형 |
| 5학년 | 동치분수·약분·기약분수·공통분모·통분·비교: 6유형; 다른 분모 덧셈·뺄셈과 대분수·받아내림: 7유형; 자연수·진분수·대분수 곱셈과 계산 중 약분: 5유형 |
| 6학년 | 분수÷자연수, 자연수÷분수, 분수÷분수, 대분수가 포함된 나눗셈: 4유형 |

총 5단원, 29유형에 기초·기본·도전 난이도와 5·10·20문제를 제공한다. 4·5학년 덧셈과 뺄셈 단원에서는 덧셈만 또는 뺄셈만 골고루 섞는 선택도 제공한다. 이 선택은 기존 세부 유형을 묶어 출제하므로 29유형에 별도로 더하지 않는다. 사용자가 요청한 학습 범위를 구현 기준으로 삼았다.

## 전자칠판 수업 모드

처음에는 한 문제만 제시한다. 교사가 힌트, 정답, 풀이를 공개하고 풀이는 한 단계씩 전환한다. 문제를 항상 함께 표시한다. 이전/다음, 같은 유형의 새 문제, 새 세트, 단원·유형 변경, 전체화면, 단축키 도움말을 제공한다. 수업 화면에 개인 점수나 정답 입력은 표시하지 않는다.

수업 마무리 화면에서 `이번 회차 문제와 정답 보기`를 펼치면 해당 세트 전체를 확인한다. 기존 서비스와의 기능 대조에서 누락을 발견한 정답 모음, 4학년 자연수−대분수, 덧셈·뺄셈별 섞기 선택을 복원했다.

전자칠판 터치에 적합한 텍스트 버튼과 방향키·Space·H·S·F를 지원한다. 도움말·입력 필드에서는 단축키를 차단한다. 이전 문제의 공개 상태를 보존하며 처음 방문하는 다음 문제는 정답을 숨긴다.

선택 타이머는 상단 정보 행에 표시한다. 기본은 끄기, 10·20·30·60초 및 직접 설정을 지원하며 T로 시작/일시정지, R로 초기화한다. 시간 종료 후 자동 이동은 없고 정답 공개만 선택할 수 있다. 이미 공개한 풀이·그림을 만료 이벤트가 덮어쓰지 않는다.

## FHD 화면 최적화

`100dvh`의 전용 화면을 상단 정보, 문제·공개 영역, 주요 조작, 보조 도구의 네 행으로 나눴다. 분수는 충분한 굵기의 분수선과 세로 분자·분모를 사용하고, 대분수의 자연수 부분을 별도로 정렬한다. 모든 공개 내용을 한꺼번에 쌓지 않아 한 문제의 가독성과 설명 공간을 유지한다.

1920×1080에서 기본 문제 숫자 약 142px, 정답 공개 후 문제 약 107px, 정답 약 111px, 풀이 계산식 약 77px이며 주요 조작 버튼 높이는 108px이다. 4K에서는 화면 크기에 비례해 커지고, 노트북·태블릿에서는 문제와 풀이 비율을 조절한다. 검증은 문서 크기뿐 아니라 실제 문제·풀이·그림·버튼의 경계까지 검사한다.

## 개인 학습 모드

분수·대분수·자연수 입력, 자동 포커스, Tab 이동, Enter 제출, 비교 기호 선택, 즉시 판정, 재도전, 힌트와 단계별 풀이를 구현했다. 틀린 문제, 풀이를 먼저 본 문제, 건너뛴 문제를 결과 및 저장된 기록에서 다시 풀 수 있다.

학습 날짜·학년·단원·유형·문제 수·정답 수·첫 제출 정답률·학습 시간·시도 내역·오답을 저장한다. 첫 제출 정답과 재도전 성공을 구분하며, 수업 모드에는 개인 기록을 생성하지 않는다. 저장소가 없거나 용량이 부족하면 메모리 보관과 안내를 제공한다.

## 성취와 학급 랭킹

개인 학습에서 선택적으로 성장 점수·경험치·레벨·배지를 제공한다. 정답률 계산은 기존과 같고 보상은 별도 저장한다. `나의 성장`에 누적 상태를 표시하고 결과·기록에는 해당 세트의 점수·경험치·최대 연속 정답·타이머 정보를 표시한다. 기존 학습 기록을 조회하는 것으로 보상을 새로 지급하지 않는다.

학급 선택과 랭킹 참여를 분리했다. 학교 검색 후 4~6학년과 1~30반을 선택하고 개인 학습 설정에서 온라인 또는 데모 참여를 켠다. 5문제 이상 끝까지 학습한 새 세트만 반영한다. 온라인 성장 점수·기기의 데모·예전 점수는 분리하며 이번 주/지난주를 한국 시간 월요일 기준으로 조회한다. 온라인 반영 실패는 개인 기록에 남겨 재시도한다. 운영 서버 쓰기와 권한 규칙은 변경하거나 검증하지 않았다.

## 문제 생성 규칙

유형별 규칙을 먼저 적용하고 그 범위 안에서 숫자를 선택한다. 4학년은 같은 분모, 5학년 덧셈·뺄셈은 서로 다른 분모, 곱셈·나눗셈은 지정된 자연수·진분수·대분수 조합을 보장한다. 합의 범위, 양의 결과, 받아내림, 계산 중 약분 등 유형의 의미를 검사한다.

기초는 한 분모가 다른 분모의 배수인 통분과 단순한 대분수 계산, 도전은 복합 단계·올림·대분수 조합으로 구성한다. 분모 후보와 계산 결과를 제한하며 기약분수 결과 분모 상한은 난이도별 24·48·60이다. 음수·0분모·0으로 나누기는 출제하지 않는다. 세트 안의 동일 문제는 제거하며 이전 세트도 가능한 한 피한다. 후보가 소진되면 이전 세트 중복은 제한적으로 허용하되 새 세트 내부에는 중복을 넣지 않는다.

## 정답 판정 방식

정수 및 BigInt 중간 계산을 사용해 부동소수점 오차를 피한다. 분모 0, 빈칸·부분 입력, 소수·음수·지수 표기, 입력 한계를 검증한다. 값은 교차 곱으로 비교하고 기약분수 조건이 있을 때만 최대공약수까지 검사한다. 통분은 값과 요구 분모를 모두 확인한다.

분모끼리 더한 오류, 분자에 배수를 적용하지 않은 통분, 약분 필요, 대분수 변환, 나눗셈 역수 오류 등에 별도 피드백을 제공한다. 모든 오답의 원인을 단정하지 않으며 해당 패턴이 아닌 경우 계산 힌트를 준다.

## 테스트 결과

계산·출제 자동 검사와 실제 Chrome의 전자칠판·개인 학습 시나리오를 통과했다. 최종 검사 수, 해상도별 수치, 계산 예제 및 검증 범위는 [TEST-RESULTS.md](TEST-RESULTS.md)에 기록한다. 별도의 빌드 과정은 없다.

## 아직 구현하지 않은 기능

요청의 핵심 학습·출제·수업·저장과 이번 타이머·성취·학급 랭킹 연결을 구현했다. 계정 및 기기 간 동기화, 교사용 학급 대시보드, 학습지 인쇄·PDF, 앱 내 판서 도구, 조작 가능한 개념 애니메이션은 추가 확장 항목으로 남아 있다. 온라인 랭킹의 실제 운영 쓰기·보안 규칙, 실제 전자칠판 하드웨어와 모든 브라우저 조합의 현장 검증은 완료하지 않았다.
