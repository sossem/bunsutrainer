### 전자칠판 수업 흐름

요청한 다음 흐름을 실제 클릭과 키보드 이벤트로 검증했다.

1. 전자칠판 → 5학년 → 분수의 덧셈과 뺄셈 → 기본 → 10문제.
2. 문제만 표시, 정답·풀이 숨김.
3. 힌트만 공개 → 정답 공개 → 풀이 및 모든 단계 전환.
4. 다음 문제에서 정답 숨김, 이전 문제에서 공개 상태 복원.
5. 방향키·H·Space·S 단축키.
6. 도움말 및 입력 칸에 포커스가 있을 때 단축키 차단.
7. 전체화면 F 진입·종료 및 Esc 종료.
8. 정답 공개 후 교사 조작 버튼의 키보드 포커스 유지.
9. 마지막 문제와 수업 마무리, 점수 없는 종료 화면, 새 세트.
10. 같은 유형의 새 문제로 즉시 교체.
11. 수업 마무리에서 이번 회차 문제·정답 모음 열기, 모든 문제와 정답의 일치 및 FHD·노트북·모바일 가로 경계 확인. 수업 정답 모음은 세로로 스크롤하며 확인한다.
12. 자연수−대분수 선택·필수 받아내림 옵션·자연수 표시·동치 답 판정, 4·5학년 덧셈/뺄셈만 섞기 및 대분수 제외 옵션.

페이지 새로고침 없이 수업 흐름을 수행했다. 대분수 받아내림·곱셈·나눗셈과 동치·약분·통분·비교 화면도 각각 정답, 풀이의 모든 단계, 지원 시각 모델을 검사했다.

FHD에서 문제 숫자 142.08px, 공개 후 문제 106.56px, 풀이 숫자 76.8px, 주요 버튼 높이 108px를 확인했다. 4K의 풀이 숫자는 153.6px, 주요 버튼 높이는 216px이다. 화면 크기는 브라우저 내부 viewport 기준이다.

문서의 scrollWidth/scrollHeight뿐 아니라 문제 영역 안의 분수·계산식·설명·시각 모델과 버튼의 실제 사각형 경계를 검사했다. CSS의 overflow 숨김만으로 성공으로 처리하지 않는다. 모바일은 세로 스크롤바가 차지하는 공간을 제외한 clientWidth와 비교한다.

### 개인 학습·기록

## 선택 기능의 실제 연결 검증

`index.html`의 CSS 4개와 JS 10개 파일 경로 및 `defer` 로드 순서를 확인했다. `gamification.js`는 제출·완료 보상과 성장 화면에, `timer.js`는 문제별 시계·설정·단축키에, `ranking.js`는 학교 검색·학급 선택·조회·완료 기록 반영에 `session-extras.js`와 `ranking-ui.js`를 통해 연결된다.

- 타이머: 기본 끄기, 직접 입력 검증, T/R, 정지·재개·문제 이동·교체·도움말·설정 복귀, 만료 후 입력, 선택적 정답 공개, 타이머를 켠 FHD·일반 화면을 확인했다. 단위 검사로 만료 중복·오래된 콜백·시간 보너스 경계를 확인했다.
- 보상·저장: 세트 완료 점수·경험치·배지·기록 복원, 중복 지급 방지, 도구 끄기, 기존 버전 1 기록 및 저장 제한을 확인했다.
- 랭킹: 실제 학교 데이터 검색, 학급 선택, 데모 완료 반영·중복 방지, 이번 주/지난주, 상위 50개와 우리 반, 오류·재시도·지연 응답을 확인했다. 자동 랭킹 시나리오의 온라인 공급자와 Firestore 쓰기 트랜잭션은 로컬 모의 구현으로 검사했다.
- 별도 실제 조회: 테스트 전용 브라우저에서 운영 온라인·예전 점수의 조회 버튼을 각각 1회 실행했다. Firebase SDK 로드 및 Firestore 조회가 성공했고 당시 각각 1개·2개 행이 표시되었다. 콘솔 오류는 없었다. 점수 전송이나 운영 데이터 변경은 수행하지 않았다.
