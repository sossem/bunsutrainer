# 분수트레이너 구현 구조 및 기존 코드 분석

## 2026-09-14 현재 구조

현재는 홈의 **선생님과 함께 수업 / 전국학급랭킹전**으로 시작한다. 상단 메뉴는 학급 랭킹·학습 기록·단축키 안내이며 홈 하단 학년별 설명은 제거했다. 전자칠판의 세부 설정·타이머·전체화면·힌트·정답·풀이·문제 이동을 유지하고, 개인 학습은 주간 닉네임으로 입장해 카드형 문제 유형·난이도·문제 수를 선택한다. 개인 학습의 대분수·받아내림 체크박스와 타이머 도구는 제거했으며 계산·출제·판정 엔진은 유지했다.

`index.html`은 CSS 5개와 JS 12개를 `defer` 순서로 연결한다. `app.js`가 화면 상태와 위임 이벤트를 관리하고 `session-extras.js`가 `gamification.js`의 점수 계산, `timer.js`의 교사 전용 시계, 학습 기록 및 랭킹 기여를 연결한다. 나의 성장 화면과 경험치·배지의 신규 지급은 없으며 기존 `bunsu.game.v1` 데이터는 삭제하지 않는다. `ranking.js`의 학교 검색과 Firebase 공급자를 `competition.js`가 재사용한다. 신규 `competition-ui.js`·`css/competition.css`는 입장과 학급/개인 랭킹을, 기존 `ranking-ui.js`·`css/ranking.css`는 이전 방식의 랭킹 조회를 담당한다.

닉네임 후보와 최대 10회 주사위 횟수는 학급·주간별로 저장한다. 확정 시 Firestore 트랜잭션으로 같은 반·같은 주의 중복 닉네임을 막고, 입장 시 등록 정보를 조회한다. 닉네임을 잊어 새로 발급받아도 이전 개인 점수는 유지한다. 난이도별 정답 점수 10·11·13점과 첫 시도/연속 정답 보너스는 기존 `LearningGame.scoreAnswer()`에서 계산하며 시간 보너스는 발생하지 않는다.

주간은 한국 시간 월요일 오전 8시에 전환한다. `weeklyCompetitionClasses_YYYYMMDD`, `weeklyCompetitionPlayers_YYYYMMDD`, `weeklyCompetitionReceipts_YYYYMMDD`를 사용해 학급·개인 점수와 중복 방지 영수증을 한 트랜잭션에서 갱신한다. 지난주 저장 공간을 그대로 보존하고 현재/지난주를 실시간 구독한다. 경계 시각에는 새 주간을 구독하고 만료된 닉네임·지난주 점수 제출을 거부하므로 별도 서버 초기화 예약 작업은 없다. 화면을 떠나거나 탭을 숨기면 실시간 구독과 주간 전환 예약을 정리한다.

기존 localStorage 키 4개와 `bunsu.learning.v1`의 version 1을 유지한다. 주간 아이디와 후보만 `bunsu.competition.identity.v1`, `bunsu.competition.drafts.v1`에 저장하고, 학습 기록의 `competition`은 이전 기록에 없어도 되는 선택 필드다. 새로운 랭킹은 과거 `classGrowthRankings_*`·`classRankings_*` 및 데모와 합산하지 않는다. 실제 검증 결과와 운영 환경의 한계는 [TEST-RESULTS.md](TEST-RESULTS.md)를 따른다.

**아래는 최초 재설계와 2026-09-13 연결 작업의 이전 버전 기록이다.** 아래의 개인 타이머·나의 성장·데모 참여 계획은 당시 구현을 설명하며 현재 동작은 위 내용과 [README](../README.md)가 우선한다.

## 작업 전 분석

기존 프로젝트는 873줄 index.html, 학교 검색 데이터 elementaryschooldata.json, Git 작업 및 로컬 서버 실행 배치 파일로 구성되어 있다. 최초 분석 당시 redesign 브랜치이며 작업 트리가 깨끗했다. 중단 후 재개할 때는 이 문서와 기존 미완성 변경사항을 보존하여 이어서 작업했다.

- 목적: 4학년의 분모가 같은 분수 덧셈·뺄셈 수업 연습과 전국 학급 점수 경쟁.
- 화면: 유형 선택, 10문제 진행, 정답 모음, 학교·학급 선택 모달, 주간 랭킹.
- 출제: 분모 3~9, 같은 분모 고정. 진분수 덧셈/뺄셈, 대분수 덧셈, 1−진분수, 받아내림 유무별 대분수 뺄셈, 자연수−대분수. 중복 검사가 없고 학년·단원·난이도 구분도 없다.
- 판정: 대분수를 가분수로 환산해 교차 곱으로 동치 비교. 입력을 parseInt로 처리하고 빈 필드·부분 입력·0분모를 엄격히 검증하지 않는다. 기약분수 조건은 없다.
- 점수: 랭킹전 정답당 500점 + 남은 시간에 비례한 최대 500점. 오답은 3초 대기 후 다음 문제. 오답 시 타이머를 즉시 중단하지 않아 중복 전환 가능성이 있다.
- 기록: Firebase Firestore의 주별 classRankings 컬렉션에 학급 누적 점수와 횟수를 기록. 개인별 정답률·오답·시간 기록 및 localStorage 사용은 없다.
- CSS: 인라인 style과 단일 style 블록 혼재. 큰 카드 내부 여백과 세로 흐름 때문에 FHD 한 화면 내 표시를 보장하지 못한다.
- JavaScript: 전역 상태, 인라인 이벤트, DOM 변경, 계산, 타이머, Firebase 처리 결합. 5·6학년으로 확장하기 어렵다.

## 유지할 원리와 변경할 구조

세로 분수 표시, 대분수 입력, 교차 곱에 의한 동치 판정, 사전 문제 세트 개념을 유지했다. 함수 구현은 검증 가능한 공통 엔진으로 분리했다. 기본 학습의 Firebase SDK 의존과 자동 시간 초과 전환을 제거했다. 이후 확장에서는 선택적인 랭킹 조회·참여 때만 Firebase를 연결하고 예전 점수는 읽기 전용으로 보존한다. 기존 학교 데이터와 작업 도구는 보존한다.

## 정보 구조와 화면 계획

진입은 학습 방식 → 학년 → 단원 → 세부 유형 → 난이도 및 문제 수 순서. 교육과정 데이터는 학년 → 단원 → 유형으로 분리한다. 사용자가 제공한 학습 범위를 구현 기준으로 삼는다.

전자칠판은 전용 프레젠테이션 화면이다. 1920×1080 기준 상단 약 8%, 핵심 문제 및 공개 공간 약 74%, 교사 조작 약 18%의 화면 높이를 사용한다. 세로 페이지 스크롤 없이 한 문제를 제시한다. 힌트, 정답, 풀이, 시각 모델을 서로 교체하며 풀이를 한 단계씩 표시한다. 이전/다음 이동, 새 문제, 새 세트, 전체화면, 단축키를 제공한다. 이전 문제는 공개 상태를 보존하고 처음 방문하는 문제는 답을 숨긴다.

개인은 입력 → 판정 → 재도전 또는 풀이 → 다음 → 결과 → 오답 재학습 흐름이다. 통분 문제는 같은 분모로 바꾼 두 분수를 입력한다. 동치 문제는 빈 분자, 최소공통분모 문제는 자연수, 비교 문제는 기호를 입력한다.

## 구현 분담

- index.html: 정적 진입점, 로컬 스크립트와 CSS 로드.
- css/style.css: 시작·설정·개인학습·기록 및 공통 수학 표시.
- css/classroom.css: 전자칠판의 화면 비율, 가독성, 큰 버튼, 반응형.
- js/fraction.js: 정수 기반 분수 엔진, 입력 검증 및 문제 목적별 채점.
- js/problem-generator.js: 학년·단원·유형 카탈로그, 제한된 출제, 힌트와 풀이 데이터.
- js/storage.js: UI와 독립적인 버전 관리 localStorage 저장소.
- js/ui.js: 안전한 수학 표시, 아이콘, 분수 시각 모델.
- js/app.js: 모드별 화면, 상태, 조작, 기록과 오답 흐름.
- js/gamification.js: 점수·경험치·레벨·배지·학급 기여 계산과 보상 중복 방지.
- js/timer.js: 화면과 독립적인 단일 문제 타이머와 만료·정지·초기화.
- js/ranking.js: 학교 검색, 학급 선택, 온라인·데모·예전 점수 공급 계층.
- js/session-extras.js: 설정·타이머·정답 보상·결과·기록과 기존 학습 흐름의 연결.
- js/ranking-ui.js, css/ranking.css: 학급 선택과 랭킹 화면.
- css/extensions.css: 기존 문제 영역 크기를 유지하는 선택 학습 도구 스타일.
- tests/: 계산·출제 불변식 테스트, 브라우저 시나리오와 viewport 측정.

프레임워크나 빌드 도구 없이 일반 script defer를 사용해 정적 배포 및 index.html 직접 열기를 지원한다.

## 2026-09-13 재개 점검 및 연결 (이전 버전 기록)

재개 시 `index.html`에는 기본 계산·출제·저장·표시·앱만 연결되어 있었고 타이머·성취·랭킹 세 파일은 미연결 상태였다. 기존 5단원·28유형과 전자칠판 레이아웃을 보존하면서 필요한 스크립트·CSS와 이벤트 연결을 추가했다. 타이머는 렌더링마다 새로 만들지 않고 문제별 상태를 유지하며, 화면을 떠날 때 정지하고 세트를 교체할 때 정리한다.

학습 저장의 key/version 1과 기존 필드를 유지하고 성취·타이머·학급 반영 정보를 선택 필드로 추가했다. 학급 선택은 세트 시작 시 복사해 나중에 다른 학급을 골라도 완료 기록의 대상을 바꾸지 않는다. 완료 결과는 한 번만 확정하며 경험치와 학급 반영은 세션 식별자로 중복을 막는다. 진행 중 기록 삭제 후 늦게 도착한 서버 응답이 기록을 복구하지 않도록 처리했다.

이후 기존 서비스와 기능을 대조하면서 누락된 4학년 자연수−대분수(`whole-minus-mixed`)를 복원해 현재는 5단원·29유형이다. 4·5학년 덧셈과 뺄셈 단원에는 기존 세부 유형 중 덧셈만 또는 뺄셈만 골고루 섞는 선택(`addition`/`subtraction`)을 복원했다. 수업 마무리에는 접었다 펼치는 문제·정답 모음을 추가했다. 완료된 화면과 기존 유형은 보존하고 누락된 기능만 보완했으며, 재실행한 테스트와 브라우저 검증 결과는 [TEST-RESULTS.md](TEST-RESULTS.md)에 기록한다.

## 검증 계획

요청된 약분·통분·사칙연산·대분수·동치 계산과 경계 입력을 자동 검사한다. 모든 유형의 난이도별 표본에 대해 분모, 음수, 동치, 중복, 학년 제한을 검사한다. 실제 Chromium에서 1920×1080 수업 흐름과 여러 화면의 문서/요소 경계를 측정하고 화면을 저장한다. 검증 결과와 한계는 TEST-RESULTS.md에 기록한다.
