# 요청 기능 구현 및 검증 (2026-09-23)

## 수정 전 분석

`index.html`은 앱 컨테이너와 CSS·스크립트 로딩만 담당합니다. `app.js`가 홈 → 입장/설정 → 문제 → 결과/기록 화면, 메모리 세션과 문서 단위 위임 이벤트를 관리합니다. `fraction.js`의 정확한 분수 연산·정답 판정, `problem-generator.js`의 학년/단원/난이도별 출제, `ui.js`의 분수·풀이·시각 모델은 변경하지 않았습니다.

개인 학습은 현재 전국학급랭킹전 입장을 사용합니다. `competition.js`는 Firestore 주간 닉네임 등록·점수 트랜잭션·중복 영수증·실시간 구독을, `competition-ui.js`는 입장·랭킹 화면을 담당합니다. `ranking.js`의 기존 온라인/데모/이전 랭킹은 별도이며 샘플은 데모에만 사용합니다.

`session-extras.js`가 점수 계산(`gamification.js`)과 전자칠판 타이머(`timer.js`)를 연결합니다. 현 서비스의 경험치·배지 지급 비활성 상태를 유지했습니다. 저장 모듈은 학습 기록 100개와 확장 필드를 보존합니다. 전자칠판은 전용 CSS의 화면 높이 그리드와 단축키·전체화면을 사용합니다.

## 구현

1. 숫자 6자리 PIN을 두 번 입력해 닉네임을 등록합니다. 무작위 salt와 PBKDF2-SHA256 검증값을 사용하며 PIN 원문은 저장하지 않습니다. 재접속 시 PIN을 다시 확인합니다. 5회 오류 후 현재 창에서 30초 대기합니다. PIN 도입 전 닉네임은 기록을 남기고 새 닉네임을 발급받도록 안내합니다. 소유자를 검증할 수 없는 기존 닉네임에 선착순으로 PIN을 붙이지 않습니다.
2. 랭킹전 설정은 등록 학급의 학년만 표시합니다. 학년·단원 선택 처리, 새 세트 시작 및 기록 반영에서도 학년을 검사합니다. 전자칠판 학년 선택과 이전 오답 재학습은 유지합니다.
3. 도움 없는 첫 시도 정답에 `반올림(기본점수 × 0.5 × max(0, 1 − 풀이시간/60))`을 추가합니다. 기본점수·콤보·정답 판정은 유지합니다. 이전 문제로 이동해도 랭킹전 풀이 시작 시각을 새로 부여하지 않습니다. 별도 타이머 interval은 만들지 않습니다.
4. 기본적으로 접힌 연습장을 추가했습니다. Pointer Events로 마우스·터치·펜을 받고, 문제별 벡터 필기를 메모리에 유지하며 ResizeObserver로 다시 그립니다. 펜·지우개·되돌리기·지우기를 제공합니다. 새 렌더링 때 이전 observer를 정리하며 문서에 입력 리스너를 중복 등록하지 않습니다. FHD/노트북은 오른쪽, 좁은 전자칠판은 겹침 패널, 좁은 개인 화면은 아래쪽 패널을 사용합니다.
5. 주간 학급·개인 랭킹과 기존 랭킹의 1~3위에 접근성 순위 이름을 가진 금·은·동메달을 표시합니다.

## 데이터 및 운영 범위

기존 localStorage 키를 변경하거나 데이터를 초기화하지 않았습니다. 기존 개인 기록·점수·주사위 후보와 주간 서버 문서를 보존합니다. 새로운 학습 기록은 `scoringVersion: 3`이며 기존 버전 2와 버전 미지정 기록도 계속 읽습니다. 과거 점수를 소급 계산하지 않습니다. 신규 서버 학생 문서에 `pinCredential`만 추가하며 필기는 저장하지 않습니다.

**PIN은 현재 정적 앱의 기본적인 입장 확인입니다.** Firestore 직접 접근을 허용하는 서버 규칙 아래에서는 클라이언트 검사·대기 시간을 우회할 수 있고, 읽기 가능한 검증값에 대한 오프라인 추측도 가능합니다. 서버 직접 접근까지 차단하려면 서버에서 PIN을 검증하고 시도를 제한한 뒤 인증 사용자에 맞춘 Firestore 규칙을 적용해야 합니다. 이번 작업은 서버 인증을 배포하거나 운영 보안 규칙을 변경한 작업이 아닙니다. HTTPS 또는 localhost가 필요합니다.
